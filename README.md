# 🧮 PyCalc

### A Simple Desktop Calculator built with Python & Tkinter

PyCalc is a lightweight desktop calculator application developed using **Python** and **Tkinter**.  
It provides a clean graphical interface for performing basic mathematical operations quickly and easily.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear and reset functionality
- ⚡ Real-time expression evaluation
- 🖥️ Simple desktop GUI
- 🚫 Basic error handling for invalid expressions

---

## 🛠️ Tech Stack

- **Python**
- **Tkinter**
- **GUI Programming**
